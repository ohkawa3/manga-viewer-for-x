# Manga Viewer for X v0.7.0

X（旧Twitter）の画像をクリックすると、漫画向けの縦連結ビューアを開く Chrome 拡張です。X社とは無関係の非公式ツールです。

[English README](README.en.md)

## インストール / 更新
1. zip を展開してフォルダにする（旧版がある場合はフォルダごと置き換え）
2. Chrome で `chrome://extensions/` を開き、右上の「デベロッパー モード」をON
3. 「パッケージ化されていない拡張機能を読み込む」→ 展開したフォルダを選択
   - v0.3.0 からの更新は拡張カードの↻でOK。v0.2.0（X Manga Viewer）からの更新は、旧版を削除してから読み込み直してください（名前とバックグラウンド処理が変わったため）
4. x.com のタブをリロード

## 使い方
- ツイートの画像をクリック → ビューアが開く
- 同じ投稿者のスレッド（連続返信）内の画像を投稿順に縦連結
  - ツイート詳細ページ（/status/...）で開いた場合：そのページのスレッドを読み込む
  - タイムライン・検索・リスト等で開いた場合：ビューアを開いたまま裏で詳細ページへ移動し、スレッドを読み込む。閉じると元の画面に戻る
- 中クリック / Ctrl(⌘)+クリック → 新しいタブで詳細ページを開き、そのタブを表示したときにビューアが開く（Shift を足すと前面に開く）
- Shift+クリック（新しいウィンドウ）と Alt+クリックは通常動作
- 常に最高画質（name=orig）。失敗時は 4096x4096 → large にフォールバック
- 右上のツールバーは普段は透明で、マウスを右上に持っていったときだけ表示されます（読む邪魔にならないため）。透明な間もその位置のクリックはツールバーが受けるので、画像のクリック送りは効きません。キー操作（1〜6、+/-、0、Esc など）は透明なままでも使えます

| 操作 | 動作 |
|---|---|
| ホイール / ↑ ↓ / Space | 上下スクロール |
| Ctrl+ホイール | 拡大縮小（カーソル位置基準） |
| 画像クリック / → / j / n | 次の画像の先頭へ |
| Shift+クリック / ← / k / p | 前の画像へ |
| 1〜6 | 表示モード（ボタンの並び順：同幅 / 同倍 / 横幅 / 全体 / 自動 / 原寸。設定で隠したモードは無効） |
| + / - / 0 | 拡大 / 縮小 / 倍率リセット |
| Esc / q / 余白クリック | 閉じる |

## 設定画面
`chrome://extensions/` → この拡張の「詳細」→「拡張機能のオプション」（または拡張アイコンを右クリック →「オプション」）で開きます。変更は自動で保存され、開いている x.com のタブにも反映されます。
- **起動時の表示モード**：「前回選んだモード」（既定。ビューアで最後に選んだモードで始まる）か、いずれかのモードに固定
- **表示するモード**：使わないモードのチェックを外すと、ツールバーと数字キーから見えなくなります（最低1つは残ります）。
- **基準幅**：同幅・同倍モードの基準幅（30〜100%、既定 75%）
- 「初期値に戻す」で上の2つを既定に戻せます

## 表示モード
| モード | 考え方 | 各画像の表示幅 |
|---|---|---|
| 同幅 | 連続投稿は同じ幅でそろえて読むべきとし、画像ごとに倍率を変える（既定） | 基準幅 |
| 同倍（同倍率） | 連続投稿は同じ解像度で描かれていると仮定し、全画像に同じ倍率を使う | 先頭画像が基準幅になる倍率 × 各画像の幅 |
| 横幅 | 画面幅に合わせる | 画面幅 |
| 全体 | 1枚が画面に全部収まる | 画面高さ × 縦横比（画面幅まで） |
| 自動 | 縦長は幅、横長は画面に収める | 原寸以上には拡大しない |
| 原寸 | 画像の画素のまま | 画像の幅 |

- 基準幅は画面幅に対する割合で、既定は 75% です。設定画面（上記）で 30〜100% の範囲で変えられます。その場で大きさを変えたいときは、ツールバーの ＋/− か Ctrl+ホイールの拡大縮小で調整します（モードを切り替えると 100% に戻ります）
- 同倍率では、画像の大きさの違い（見開き・差し込みの小さい画像など）がそのまま表示に反映されます。先頭画像より幅の広い画像は基準幅を超え、横スクロールになることがあります
- 同倍率の基準画像（先頭）は優先して読み込みます。読み込み前は他の読込済み画像で代用し、未読込の画像は基準と同じ画素幅と仮定して枠を取ります（読み込み後に正しい幅へ）
- ＋/− の拡大縮小は、どのモードでも上の幅にさらに掛かります

## セキュリティ・プライバシー上の設計
- 権限は `storage` のみ（`tabs` 権限・ホスト権限なし。他のタブのURLや内容は読めない）
- 外部への送信なし。画像は X が表示しているのと同じ `https://pbs.twimg.com/media/...` から読み込む
- 画像URLは `pbs.twimg.com/media/<英数字>` だけを許可し、検証後に組み立て直す
- バックグラウンド処理は「中クリック時に新しいタブを開き、そのタブに開く画像の番号を渡す」ことのみ。受け渡しには `chrome.storage.session`（ブラウザ終了で消える）を使い、一度読んだら消す。受け取る値はすべて形式を検証してから使う
- ビューアは closed Shadow DOM 内に構築（Xのページからビューアの DOM は読めない）。ただし、どの画像を読み込んだかは通常の画像読み込みと同様にページ側から観測できます
- ビューア表示中はフォーカスを外に出さず、ページ側が合成したキー・クリック操作には反応しない（裏の X のボタンが誤って押されないように）
- センシティブ警告（ぼかし・オーバーレイ）中の画像はクリックを横取りせず、スレッドにも含めない。画面外の画像は判定できないため、画面内に入って確認できるまで保留する
- 設定（表示モード・起動時のモード・基準幅）は chrome.storage に保存（x.com の localStorage は使わない）
- スレッドの自動読み込みは最大約35秒。「もっと見つける」等のおすすめ欄に到達した時点で停止
- 自動読み込みはページを実際にスクロールして行うため、X 側では通常の閲覧と同じように表示（インプレッション）が記録されます

## 制限
- 引用ツイート内の画像・プロフィールのメディア欄から開いた場合は、そのツイートの画像のみ
- 「返信をもっと表示」の先は読み込まない
- センシティブ判定・おすすめ欄の判定はXの画面構造に依存する推定です
- 同倍で、ある画像だけ最高画質の取得に失敗して低い画質で表示された場合、その画像は小さく表示されます
- XのDOM構造が変わると動かなくなる可能性があります

## 言語
画面の表示は、ブラウザの表示言語に合わせて自動で切り替わります（日本語 / 英語。日本語以外のブラウザでは英語）。文言は `_locales/<言語>/messages.json` にあり、言語を足すときはこのフォルダに追加します。
